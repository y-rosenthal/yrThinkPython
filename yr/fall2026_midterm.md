# Fall 2026 midterm

These pages show the questions of the midterm. Under each part of a question is the right answer, and then the steps that lead to that answer. A full answer needs every one of its steps.

## Which version did you have?

The midterm had two versions. The two versions ask the same kinds of questions, but the values in the code are different, so the answers are different. Use the page of your own version.

| | Version 1 | Version 2 |
|---|---|---|
| Question 1 starts with | `a = 7` | `a = 5` |
| Question 10 starts with | `s = 'Python'` | `s = 'Sunday'` |
| The small mark at the top of the question pages | K4 | R7 |
| The page | [Fall 2026 midterm, version 1](fall2026_midterm_version1.md) | [Fall 2026 midterm, version 2](fall2026_midterm_version2.md) |

So: if question 1 of your test starts with `a = 7`, you had version 1. If it starts with `a = 5`, you had version 2.

## How to use the pages

- Cover the answer of a part, work it out again, and then compare.
- If your answer was different, read the steps one at a time and find the first step that you did differently. That step is the thing to review.
- Part II has one correct function for each question, and a list of what a correct function has. Other correct ways to write a function exist.
