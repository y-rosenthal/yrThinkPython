10b. Additions: The get Method#

Additions to Chapter 10: Dictionaries: the get method of dictionaries. The chapter teaches get only in an exercise at the end of the chapter, so this page states it here, where it is easy to find. Read this page after the chapter. The practice questions at the end have answers: try each question first, then open its Answer.

def download(url):
    filename = basename(url)
    if not exists(filename):
        from urllib.request import urlretrieve

        local, _ = urlretrieve(url, filename)
        print("Downloaded " + str(local))
    return filename

The get method#

Dictionaries have a method called get that takes a key and a default value. If the key appears in the dictionary, get returns the corresponding value; otherwise it returns the default value. Its general form is:

DICT.get(KEY, DEFAULT)

For example, here is a dictionary that maps letters to counts:

counts = {'b': 2, 'r': 2, 'o': 2}
print(counts.get('b', 0))
print(counts.get('c', 0))

2
0

'b' appears in the dictionary, so get returns its value, 2. 'c' does not appear, so get returns the default value, 0. Looking up a missing key with square brackets raises a KeyError; get returns the default instead.

Without a second argument, get returns None for a missing key:

counts = {'b': 2, 'r': 2, 'o': 2}
print(counts.get('b'))
print(counts.get('c'))

2
None

get is useful for counting. Without get, a counting loop needs an if statement to check whether the key is already in the dictionary. With get, the update is one line:

counter[letter] = counter.get(letter, 0) + 1

If letter is already a key, get returns its count, and the line adds 1. If it is not a key, get returns 0, and the line stores 1. Here is the counting function from the chapter, written with get:

def value_counts(word):
    counter = {}
    for letter in word:
        counter[letter] = counter.get(letter, 0) + 1
    return counter

print(value_counts('brontosaurus'))

{'b': 1, 'r': 2, 'o': 2, 'n': 1, 't': 1, 's': 2, 'a': 1, 'u': 2}

Downey introduces get in the first exercise of Chapter 10: Dictionaries, which asks for this more concise version of value_counts.

Question 3 (medium): what is displayed?#

Predict what this code displays. Then run the cell to check (on the website, click Show code cell output).

counter = {}
for letter in 'banana':
    counter[letter] = counter.get(letter, 0) + 1
print(counter)

Show code cell output

Hide code cell output

 
{'b': 1, 'a': 3, 'n': 2}

Answer

{'b': 1, 'a': 3, 'n': 2}

Each time through the loop, get returns the count so far, or 0 for a letter seen for the first time. The word banana has 1 b, 3 as, and 2 ns.

Question 4 (medium): write a function#

Write a function called definition that takes a dictionary of word definitions and a word, and returns the definition of the word. If the word is not in the dictionary, the function returns 'No definition found'. Use get.

For example, with d = {'apple': 'a fruit', 'book': 'a set of pages'}, definition(d, 'apple') returns 'a fruit', and definition(d, 'zebra') returns 'No definition found'.

Start from this header (replace ... with the body):

def definition(d, word):
    ...

Answer

def definition(d, word):
    return d.get(word, 'No definition found')

get returns the definition when the word is a key, and the default message when it is not.
