1. Pig Latin

QUESTION: Write a function pig_latin that converts an English word to Pig Latin, using these rules: (1) if the word begins with a consonant, move the first letter to the end of the word and add 'ay'; (2) if the word begins with a vowel (a, e, i, o, u), just add 'ay' to the end of the word. Assume the word is lowercase with no spaces. For example, pig_latin('hello') should return 'ellohay', pig_latin('python') should return 'ythonpay', and pig_latin('apple') should return 'appleay'. This exercises string indexing, slicing, concatenation, and the in operator.

######################################################################
# ANSWER
######################################################################
def pig_latin(word):
    if word[0] in 'aeiou':
        return word + 'ay'
    return word[1:] + word[0] + 'ay'


2. Remove all of one or more characters (string version)

QUESTION: Write a function remove_chars that takes a string text and a string chars, and returns a new string with every character that appears in chars removed. For example, remove_chars('hello world', 'aeiou') should return 'hll wrld'. This exercises for loops, the not in operator, and building a string one piece at a time. Note: unlike str.replace, which already removes all occurrences, there is no built-in for this on strings with several characters at once.

######################################################################
# ANSWER
######################################################################
def remove_chars(text, chars):
    result = ''
    for ch in text:
        if ch not in chars:
            result = result + ch
    return result


3. Remove all of one or more items (list version)

QUESTION: Write a function remove_items that takes a list items and a list bad, and returns a NEW list with every item that appears in bad removed. For example, remove_items([1, 2, 3, 2, 4, 2], [2]) should return [1, 3, 4]. This exercises for loops, the not in operator, and list append. Note: the built-in list.remove only removes the FIRST occurrence (and raises ValueError if the item is missing), so this function fills a real gap. Also note we return a new list instead of mutating the input -- mutating the caller's list behind their back is the Chapter 9 aliasing trap.

######################################################################
# ANSWER
######################################################################
def remove_items(items, bad):
    result = []
    for x in items:
        if x not in bad:
            result.append(x)
    return result


4. Reimplement list.count, then find the most frequent item (A/B)

QUESTION: Part A: Write a function my_count that takes a list lst and a value x, and returns how many times x appears in lst -- doing what the built-in list.count does, but using only a loop and an if. For example, my_count([1, 2, 3, 2, 4, 2], 2) should return 3. This exercises the accumulator pattern. Part B: Write a function most_frequent that takes a non-empty list lst and returns the item that appears most often (if several tie, return the one that appears first in the list). For example, most_frequent([1, 2, 1, 3, 2, 4, 2]) should return 2. Part B must use a NESTED for loop: for each item, count its occurrences with an inner loop -- the same counting idea as Part A, repeated once per item. Class discussion: compare with a version that calls my_count inside the loop (Chapter 6: building on functions you already wrote).

######################################################################
# ANSWER
######################################################################
def my_count(lst, x):
    count = 0
    for item in lst:
        if item == x:
            count = count + 1
    return count


def most_frequent(lst):
    best = lst[0]
    best_count = 0
    for x in lst:
        count = 0
        for y in lst:
            if y == x:
                count = count + 1
        if count > best_count:
            best_count = count
            best = x
    return best


5. Reimplement the in operator, then find common items (A/B)

QUESTION: Part A: Write a function my_contains that takes a list lst and a value x, and returns True if x appears in lst and False otherwise -- doing what the in operator does, but written out with a loop. For example, my_contains([1, 2, 3], 9) should return False. This exercises early return from inside a loop. Part B: Write a function common_items that takes two lists a and b, and returns a new list of the items that appear in BOTH lists, with no repeats, in the order they first appear in a. For example, common_items([1, 2, 3], [2, 3, 4]) should return [2, 3]. Part B must use a NESTED for loop: for each item in a, scan b with an inner loop. Class discussion: compare with a version that calls my_contains inside the loop.

######################################################################
# ANSWER
######################################################################
def my_contains(lst, x):
    for item in lst:
        if item == x:
            return True
    return False


def common_items(a, b):
    result = []
    for x in a:
        for y in b:
            if x == y and x not in result:
                result.append(x)
    return result


6. Reimplement list.index

QUESTION: Write a function my_index that takes a list lst and a value x, and returns the index of the FIRST occurrence of x in lst, or -1 if x is not there -- like the built-in list.index, except the real one raises ValueError instead of returning -1 (a design decision worth discussing in class). For example, my_index([10, 20, 30], 20) should return 1. This exercises range, len, and indexing.

######################################################################
# ANSWER
######################################################################
def my_index(lst, x):
    for i in range(len(lst)):
        if lst[i] == x:
            return i
    return -1


7. Reimplement str.replace

QUESTION: Write a function my_replace that takes a string s, a string old, and a string new, and returns a new string with EVERY occurrence of old replaced by new -- doing what the built-in str.replace does (assume old is not empty). For example, my_replace('hello', 'l', 'L') should return 'heLLo'. This exercises two-part slicing and keeping track of position while building a string.

######################################################################
# ANSWER
######################################################################
def my_replace(s, old, new):
    m = len(old)
    result = ''
    skip = 0
    for i in range(len(s)):
        if skip > 0:
            skip = skip - 1
        elif s[i:i + m] == old:
            result = result + new
            skip = m - 1
        else:
            result = result + s[i]
    return result


8. Reimplement str.find, then find every occurrence (A/B)

QUESTION: Part A: Write a function my_find that takes a string s and a string sub, and returns the index where sub FIRST appears in s, or -1 if it never appears -- like the built-in str.find. For example, my_find('hello', 'll') should return 2. This needs a NESTED for loop (Chapter 9b): the outer loop tries each starting position, the inner loop checks the characters one by one. Part B: Write a function find_all that takes s and sub and returns a LIST of every starting index where sub appears. For example, find_all('hello', 'l') should return [2, 3], and find_all('hello', 'z') should return []. Part B uses the same nested loop as Part A, but collects every match instead of returning the first.

######################################################################
# ANSWER
######################################################################
def my_find(s, sub):
    for i in range(len(s) - len(sub) + 1):
        match = True
        for j in range(len(sub)):
            if s[i + j] != sub[j]:
                match = False
        if match:
            return i
    return -1


def find_all(s, sub):
    result = []
    for i in range(len(s) - len(sub) + 1):
        match = True
        for j in range(len(sub)):
            if s[i + j] != sub[j]:
                match = False
        if match:
            result.append(i)
    return result


9. Reimplement str.split

QUESTION: Write a function my_split that takes a string s and returns a list of its words, splitting on spaces (treat any run of spaces as one separator, and ignore leading/trailing spaces) -- like the built-in str.split() with no arguments. For example, my_split('  too   many   spaces  ') should return ['too', 'many', 'spaces']. This exercises building words character by character and list append.

######################################################################
# ANSWER
######################################################################
def my_split(s):
    words = []
    word = ''
    for ch in s:
        if ch == ' ':
            if word != '':
                words.append(word)
                word = ''
        else:
            word = word + ch
    if word != '':
        words.append(word)
    return words


10. Reimplement str.join

QUESTION: Write a function my_join that takes a list of strings words and returns one string with a single space between them -- doing what ' '.join(words) does. For example, my_join(['hello', 'world']) should return 'hello world'. This exercises range/len indexing and careful separator handling (no trailing space).

######################################################################
# ANSWER
######################################################################
def my_join(words):
    result = ''
    for i in range(len(words)):
        if i > 0:
            result = result + ' '
        result = result + words[i]
    return result

# ANSWER
######################################################################
def my_reverse(lst):
    result = []
    for i in range(len(lst) - 1, -1, -1):
        result.append(lst[i])
    return result


12. Reimplement min, max, and sum

QUESTION: Write three functions my_min, my_max, and my_sum that do what the built-ins min, max, and sum do for a non-empty list of numbers (assume the list is not empty). For example, my_min([4, 2, 8, 1]) is 1, my_max([4, 2, 8, 1]) is 8, my_sum([1, 2, 3, 4]) is 10. These exercise the accumulator pattern and comparisons.

######################################################################
# ANSWER
######################################################################
def my_min(numbers):
    smallest = numbers[0]
    for n in numbers:
        if n < smallest:
            smallest = n
    return smallest


def my_max(numbers):
    biggest = numbers[0]
    for n in numbers:
        if n > biggest:
            biggest = n
    return biggest


def my_sum(numbers):
    total = 0
    for n in numbers:
        total = total + n
    return total

14. Check for duplicates, then list them (A/B)

QUESTION: Part A: Write a function has_duplicates that takes a list lst and returns True if any value appears more than once, False otherwise. For example, has_duplicates([1, 2, 3, 2]) is True. This exercises the NESTED for loop from Chapter 9b: compare every pair of positions. Part B: Write a function find_duplicates that takes a list lst and returns a NEW list of the items that appear more than once, each listed once, in the order of their first repeat. For example, find_duplicates([1, 2, 1, 3, 2, 1]) should return [1, 2]. Part B uses the same nested pair-loop as Part A, but collects the repeated items instead of just answering True/False.

######################################################################
# ANSWER
######################################################################
def has_duplicates(lst):
    for i in range(len(lst)):
        for j in range(i + 1, len(lst)):
            if lst[i] == lst[j]:
                return True
    return False


def find_duplicates(lst):
    result = []
    for i in range(len(lst)):
        for j in range(i + 1, len(lst)):
            if lst[i] == lst[j] and lst[i] not in result:
                result.append(lst[i])
    return result

18. Acronym builder, then acronyms for many phrases (A/B)

QUESTION: Part A: Write a function acronym that takes a phrase (a string of capitalized words separated by single spaces) and returns its acronym: the first letter of each word. For example, acronym('North Atlantic Treaty Organization') should return 'NATO'. This exercises str.split (Chapter 9), indexing, and string building. ######################################################################
# ANSWER
######################################################################
def acronym(phrase):
    words = phrase.split()
    result = ''
    for w in words:
        result = result + w[0]
    return result


def acronyms(phrases):
    result = []
    for phrase in phrases:
        words = phrase.split()
        short = ''
        for w in words:
            short = short + w[0]
        result.append(short)
    return result

20. Reimplement str.strip (stretch)

QUESTION: Write a function my_strip that takes a string s and returns it with leading and trailing spaces removed -- like the built-in str.strip(). For example, my_strip('   hello   ') should return 'hello', and my_strip('   ') should return ''. This is a stretch exercise: find the first and last non-space positions with loops, then take one two-part slice. No while loop needed.

######################################################################
# ANSWER
######################################################################
def my_strip(s):
    start = len(s)
    end = -1
    for i in range(len(s)):
        if s[i] != ' ':
            if start == len(s):
                start = i
            end = i
    if end == -1:
        return ''
    return s[start:end + 1]


21. Multiplication table (nested loops)

QUESTION: Write a function multiplication_table that takes an integer n and returns a list of n lists: the n-by-n multiplication table. For example, multiplication_table(3) should return [[1, 2, 3], [2, 4, 6], [3, 6, 9]]. def multiplication_table(n):
    table = []
    for i in range(1, n + 1):
        row = []
        for j in range(1, n + 1):
            row.append(i * j)
        table.append(row)
    return table

25. Selection sort (stretch, nested loops)

QUESTION: Write a function selection_sort that takes a list of numbers lst and sorts it in place from smallest to largest, then returns it. For example, after selection_sort([4, 2, 8, 1]) the list should be [1, 2, 4, 8]. This is a stretch exercise combining NESTED for loops (Chapter 9b) with swapping two variables through a temporary (Chapter 2). Note: this one changes the caller's list -- the Chapter 9 aliasing lesson again. Class discussion: how would you change it to return a NEW sorted list and leave the input alone?

######################################################################
# ANSWER
######################################################################
def selection_sort(lst):
    for i in range(len(lst)):
        for j in range(i + 1, len(lst)):
            if lst[j] < lst[i]:
                temp = lst[i]
                lst[i] = lst[j]
                lst[j] = temp
    return lst


26. Run-length encoding (nested loops)

QUESTION: Write a function run_length that takes a list lst (assume all items are the same type, for example all strings) and returns a NEW list that alternates between each distinct item, in sorted order, and its count. For example, run_length(['c', 'a', 'a', 'b', 'c', 'a']) should return ['a', 3, 'b', 1, 'c', 2]: three a's, one b, two c's. Hint: collect the unique items first (the question 13 idea), sort them with sorted (Chapter 9), then use a NESTED for loop to count each one. This combines Chapter 7 (counting), Chapter 9 (sorting), and Chapter 9b (nested loops) -- and it needs no dictionaries.

######################################################################
# ANSWER
######################################################################
def run_length(lst):
    uniques = []
    for x in lst:
        if x not in uniques:
            uniques.append(x)
    result = []
    for x in sorted(uniques):
        count = 0
        for y in lst:
            if y == x:
                count = count + 1
        result.append(x)
        result.append(count)
    return result

30. Store discount (nested if/else)

QUESTION: Write a function final_price that takes a price, a boolean member (True if the customer is a club member), and a coupon code string, and returns the price after discounts: members with the coupon 'SAVE10' get 10 percent off; members without the coupon pay full price; non-members with the coupon get 5 percent off; non-members without the coupon pay full price. ######################################################################
# ANSWER
######################################################################
def final_price(price, member, coupon):
    if member:
        if coupon == 'SAVE10':
            return price * 0.9
        else:
            return price
    else:
        if coupon == 'SAVE10':
            return price * 0.95
        else:
            return price


31. Triangle type (nested if containing elifs)

QUESTION: Write a function triangle_type that takes three side lengths a, b, c and returns 'equilateral' if all three sides are equal, 'isosceles' if exactly two are equal, 'scalene' if all are different, and 'not a triangle' if the sides cannot form a triangle at all (each pair must sum to more than the third side). For example, triangle_type(5, 5, 5) is 'equilateral', triangle_type(3, 4, 5) is 'scalene', and triangle_type(1, 2, 10) is 'not a triangle'. This exercises a NESTED if whose inner part is itself an if/elif/else -- nested ifs with else-ifs, exactly. Everyone already knows what the words mean, so the logic is the whole lesson.

######################################################################
# ANSWER
######################################################################
def triangle_type(a, b, c):
    if a + b > c and a + c > b and b + c > a:
        if a == b and b == c:
            return 'equilateral'
        elif a == b or b == c or a == c:
            return 'isosceles'
        else:
            return 'scalene'
    else:
        return 'not a triangle'


32. Biggest of three (nested if/else)

QUESTION: Write a function max_of_three that takes three numbers a, b, c and returns the largest -- WITHOUT using the built-in max. For example, max_of_three(3, 7, 5) should return 7. This exercises pure NESTED if/else and is perfect for tracing by hand: every path through the code returns exactly one value.

######################################################################
# ANSWER
######################################################################
def max_of_three(a, b, c):
    if a >= b:
        if a >= c:
            return a
        else:
            return c
    else:
        if b >= c:
            return b
        else:
            return c


33. Leap year (triple-nested if/else)

QUESTION: Write a function is_leap_year that takes a year and returns True if it is a leap year, False otherwise. The rules: a year divisible by 4 is a leap year, EXCEPT years divisible by 100 are not, EXCEPT years divisible by 400 are. For example, is_leap_year(2024) is True, is_leap_year(1900) is False, and is_leap_year(2000) is True. This exercises TRIPLE-NESTED if/else -- the classic example where each exception lives one level deeper. Uses % from Chapter 7.

######################################################################
# ANSWER
######################################################################
def is_leap_year(year):
    if year % 4 == 0:
        if year % 100 == 0:
            if year % 400 == 0:
                return True
            else:
                return False
        else:
            return True
    else:
        return False
